## Key Features

- **Interactive Hero Team Hotspots:** Pulsing radar pins mapped to the authentic team photo with interactive hover cards and deep profile modals.
- **Strictly Verified Profiles:** 100% of resume credentials, skills, projects, certifications, and experience are derived from official source documents.
- **Detailed Profile Drawers:** Modal views with categorized technical proficiencies, work histories, verified projects, and direct resume download/view actions.
- **Comprehensive Project Showcase:** Filterable gallery highlighting 13 real-world projects across AI/ML, Full-Stack Web, Real-Time Systems, and Enterprise Software.
- **Services Architecture:** 6 interactive modules with expandable technical capabilities.
- **Verified Resumes Hosted Locally:** PDF copies of founder resumes downloadable directly from `/resumes/`.
- **Contact & Inquiries:** Controlled inquiry form with real-time feedback and direct team communication channels (`nbstechsolutions3@gmail.com`).

## Getting Started

### Prerequisites
- Node.js 18.17 or later
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Naveen798933/NBS-TECH-SOLUTIONS.git

# Navigate to project directory
cd NBS-TECH-SOLUTIONS

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the site.

### Production Build

```bash
npm run build
npm run start
```
